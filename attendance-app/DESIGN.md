# 출석부 관리자 화면

이 문서는 2026-09-05 요청한 관리자 화면의 시각 기준이다. 교사·데모 UI 전체를 재설계하는 기준으로 확대하지 않는다. 제품·운영 사실은 `PRODUCT.md`와 기존 매뉴얼을 따른다.

## 참고와 방향

[Linear의 2026년 인터페이스 개선](https://linear.app/now/behind-the-latest-design-refresh)에서 탐색 영역의 강조를 줄이고, 위치·작업 제어를 일정한 자리에 두며, 목록의 정보 밀도를 유지하는 방식을 참고한다. Linear의 로고·이미지·제품 문구를 복제하지 않는다.

- 밝은 회색 사이드바 `#f7f7f8`와 흰 작업 영역, 경계 `#e5e5e8`.
- 본문 `#292a30`, 보조 텍스트 `#666773`, 선택·핵심 동작 `#6355a7`.
- 기존 Noto Sans KR를 유지한다. 목록 13px, 보조 11–12px, 페이지 제목 22–24px. 숫자는 tabular-nums.
- 아이콘은 `AdminIcon`의 일관된 선형 SVG. 장식용 사진·차트·애니메이션을 추가하지 않는다.

## 관리자 대시보드

Mode: Operate. 2026-09-05 사용자가 첫 화면 우선순위를 ‘주간 출석·미입력 반 중심’으로 확정했다.

첫 화면에는 주일 선택, 입력 완료·출석 인원·출석률·미입력 요약, 확인할 반 안내, 반별 목록을 둔다. 부서·학년·검색·입력 상태 필터는 목록 바로 위에 모으고, 전역 조회 연도는 셸 헤더에 둔다. 요약은 전체 범위이며 목록은 필터 범위다.

주요 조작은 `확인할 반 보기 → 반별 출석부 열기`다. 선택한 반과 주일을 전달한다. `/`는 현재 목록 검색에 포커스를 옮기며 입력 중에는 가로채지 않는다. 비율 막대는 실제 입력률을 표시하고 변화만 180ms에 반영한다. reduced-motion에서는 전환을 끈다.

## 반응형·상태

- 데스크톱은 224px 사이드바와 독립 스크롤 본문. 모바일은 상단 브랜드·가로 메뉴와 세로 본문으로 바뀐다.
- 모바일 표는 반별 묶음으로 재배치해 페이지 전체 가로 스크롤을 만들지 않는다. 검색 입력은 모바일 16px, 주요 터치 조작은 44px 이상이다.
- 선택·hover·키보드 focus를 구분한다. 경로 탐색은 `aria-current`, 상태 필터는 `aria-pressed`를 사용한다.
- 로딩·권한 오류·재시도는 기존 `DataLoadGate`를 유지한다. 빈 원장과 검색 결과 없음, 조회할 정상 주일 없음은 다른 문구와 복구 동작을 제공한다.
- 입력 완료 여부는 장결을 제외한 실제 입력 대상 기준이다. 전체 출석률은 기존 원장 통계의 장결 포함 기준을 유지하고 그 차이를 화면에 명시한다.

## 교사 출석 입력 1차 정돈 (2026-09-06)

Mode: Operate. 교사·데모 화면은 기존 `TopBar → 반 선택 → 출석 체크/출석부/건의사항 → 학생 명단 → TabNav` 구조와 최근 4회 입력 계약을 유지한다. 관리자 사이드바·검색·다중 필터·반별 표를 옮기지 않고, 관리자 화면에서 확인된 얇은 경계·중립 표면·안정된 제어 위치만 교사 역할 범위에 적용한다.

- 출석 화면의 역할 범위는 `.teacher-attendance`다. 공용 데모의 교사 역할에는 적용하고 일반 관리자 출석 화면에는 적용하지 않는다.
- 모바일 반 탭과 출석 서브탭은 44px 이상으로 유지한다. 학생·담임 카드, 날짜 선택, 주간 요약의 의미와 순서는 보존하되 세로 여백을 줄여 명단을 더 빨리 보여 준다.
- 학생 이름과 수정 가능한 출석 셀은 실제 버튼으로 제공한다. 빠른 출석·결석 버튼은 학생별 이름과 `aria-pressed`를 가지며, 같은 상태를 다시 누르면 미입력으로 돌아가는 기존 동작을 유지한다.
- 완료 행은 넓은 색 그라데이션 대신 옅은 상태 표면과 선택 버튼에 의미색을 집중한다. 선택 보라와 출석·결석 텍스트는 작은 글자에서도 읽히는 진한 색을 사용한다.

## 교사 출석 입력 2차 작업면 통합 (2026-09-06)

Mode: Operate. 1차의 구조·저장·최근 4회 계약은 유지하고, 관리자 화면의 핵심인 흰 작업면·얇은 구분선·밑줄 탭·연결형 목록을 교사 공통 셀과 출석 경로에 적용한다. 사이드바·검색·추가 필터는 도입하지 않는다.

- `.teacher-workspace`는 교사와 공용 데모의 `TopBar`·`TabNav`·`ClassTabBar`만 공통 범위로 묶는다. 관리자 `AdminWorkspace`와 통계·관리 본문 카드를 일괄 재배치하지 않는다.
- 이모지 대신 `AdminIcon`의 선형 아이콘을 사용한다. 하단 메뉴는 페이지 내비게이션이므로 `aria-current`로 현재 위치를 표시하고, 교사 셀은 본문 건너뛰기 링크와 `main` 랜드마크를 제공한다.
- 반·담당 교사·출석 대상 수는 하나의 문맥 행으로 합친다. 출석 세부 탭은 44px 이상 밑줄 탭으로 표시하고 `tab`과 `tabpanel`을 연결하며 왼우·Home·End 키 이동을 지원한다.
- 날짜 선택과 최근 4회 안내는 하나의 작업 행, 출석·결석·미입력은 평면 3열 요약으로 제공한다. 요약 아이콘·색 카드를 제거하고 tabular-nums와 세로 구분선으로 비교한다.
- 학생 명단과 출석표는 외곽 카드 대신 연결된 행 구분선을 사용한다. 출석표의 순번·이름 열은 가로 스크롤에서 같이 고정하고, 행·열 헤더와 최근 4회 수정 범위를 유지한다.
- 건의사항은 명시적 `label`과 불러오기 오류 표시를 제공한다. 내보내기 메뉴는 펼침 상태를 알리고 ESC 종료 후 초점을 복귀한다. 출석 입력·이력 모달은 6px 제어와 얇은 선을 사용하되 기존 초점 트랩·ESC·드래그 종료를 유지한다.
- 모바일 320·375·390px에서 페이지 가로 스크롤 없이 명단을 표시하고, 주요 제어는 44px 이상을 유지한다. 768·1280px에서는 본문을 최대 1120px로 중앙 정렬하며 표의 가로 스크롤은 표 내부에만 둔다.

## 출석부 진입 화면 통합 (2026-09-06)

Mode: Operate. 데모 반 선택과 관리자 로그인은 역할 판정 전의 한 진입 흐름이다. 관리자·교사 화면의 흰 작업면, 중립 텍스트, 얇은 선, `#6355a7` 핵심 동작을 공유하되 역할별 셸을 미리 렌더하지 않는다.

- `.attendance-entry`에서만 진입 화면 토큰과 반응형을 적용한다. 기존 관리자 `.admin-workspace`와 교사 `.teacher-workspace`의 레이아웃을 상속하거나 전역 입력 스타일을 덮지 않는다.
- 상단에는 선형 `book` 아이콘과 출석부 브랜드, 현재 진입 모드와 전환 동작을 둔다. 데모 반 선택과 관리자 로그인은 같은 헤더·480px 평면 패널·6–8px 제어 체계를 사용한다.
- 데모의 실제 자료 저장 안내는 제목 다음, 반 선택과 제출 전에 항상 표시한다. 최근 반, 부서·학년·반, 현재 선택, 진입 버튼의 기존 기능 순서는 유지한다.
- 목록의 첫 부서나 학년이 `1`이 아니어도 현재 옵션 안에서 유효한 값을 파생한다. 선택 확정은 기존 `{ ck, teacherName }` 계약을 유지한다.
- 로그인 이메일·비밀번호에는 명시적 레이블을 제공하고 로딩은 `status`, 오류는 `alert`로 알린다. 모바일과 200% 텍스트 확대 화면은 내용이 잘리지 않게 세로로 재배치·스크롤되며 모든 주요 버튼·입력은 44px 이상이다.

## 홈 화면 설치 안내 (2026-09-17)

Mode: Operate. 설치 안내는 출석 입력을 막지 않는 하단 배너이며, 브라우저가 실제 설치 이벤트를 제공할 때만 표시한다. 설치 앱 실행·설치 완료·사용자 닫기 상태에서는 숨긴다.

- Chromium은 기본 설치 프롬프트를 사용하고, iOS는 공유 메뉴의 `홈 화면에 추가` 방법만 간결하게 안내한다.
- 교사 모바일 화면에서는 하단 메뉴 위에 배치하고, 모든 동작은 44px 터치 영역과 키보드 초점을 제공한다.
- 별도 설치 라이브러리·모달·강제 온보딩은 추가하지 않는다. 사용자가 닫은 선택은 같은 브라우저에서 존중한다.

## 관리자 정보 구조 통합 (2026-09-06)

- `/dashboard`의 전체 현황이 주간 업무와 연간 추이의 단일 진입점이다. 이전 `/overall`도 같은 화면과 활성 메뉴를 공유한다. 별도 대시보드 메뉴를 다시 추가하지 않는다.
- 주간 출석 → 반별 입력 → 펼침형 연간 추이 순서다. 교사·학생 명단과 건의사항은 같은 전체 현황 안에서 전환한다. 연간 차트는 펼칠 때만 로드한다.
- 계정·설정은 계정 관리 / 특별 일정 / 데이터 관리로 나눈다. 검색 가능한 계정 목록과 명시적인 저장·삭제 확인을 유지한다.
- 전체 현황의 연간 표는 다른 화면의 학기 선택에 영향받지 않는다. 학생별 누적률 평균과 월별 전체 기록률의 서로 다른 계산 기준을 화면에 설명한다.
- 전체 학생 명단은 빠른 수정·이동을 위한 `간편 목록`과 연락처·생년월일까지 비교하는 `상세 표`를 같은 검색·필터 결과로 전환한다. 상세 표의 이름 열과 머리글은 스크롤 중 유지하고, 좁은 화면에서는 페이지가 아니라 표 영역만 좌우로 이동한다.

## 관리자 업무 연결·기본 보기 보완 (2026-09-23)

Mode: Operate. 기존 관리자 셸과 다섯 업무 메뉴를 유지하면서, 첫 화면의 수치 의미와 학생별 후속 작업을 명확히 한다.

- 출석률은 기존 `O / (O + X)`를 유지하고 입력된 출석 기록 수를 바로 함께 표시한다. 일반 학생의 입력 완료 인원은 별도로 표시해 두 분모를 섞지 않는다.
- 선택 주일의 출석·결석·미입력과 연도 전체의 현재 미처리 심방 요청은 제목과 묶음을 분리한다. 심방·연속 결석·미입력의 업무 순서는 유지하되, 빈 묶음은 좁은 화면에서 짧게 표시한다.
- 첫 화면의 학생별 이동은 전체 목록이 아니라 해당 학생의 목양 상세 또는 해당 심방 요청으로 연결한다. 대상이 더 이상 없을 때는 다시 검색할 수 있는 안내를 제공한다.
- PC의 전체 학생 명단은 `상세 표`, 모바일은 `간편 목록`을 첫 기본값으로 사용한다. 사용자가 선택한 보기 방식은 같은 기기에만 저장한다. 반별 출석 현황은 전체 반을 먼저 보여 주며 `확인 필요` 필터는 한 번에 선택할 수 있게 유지한다.
