## 구현

- 출석 체크·출석부 모달의 셀 저장을 `attendanceSave.ts`로 통일했다. 최신 값이 화면의 사전값과 같을 때만 ETag 조건부 PUT을 한 번 전송한다. 먼저 저장한 다른 요청은 412로 보호하고, SDK 오프라인 큐에 쓰기를 남기지 않는다.
