이관본은 shadow(조회·검수)다. 서버는 차단 항목이 남은 shadow의 setup/live 변경을 거부한다. 요청 진행 상태와 업무 쓰기 잠금을 구분하여 과거 등단·조 버전 조회, 회차 이동과 내보내기는 제공하고 생성·수정·확정은 차단한다. 동일 행사 출석을 학기 원장과 합치는 작업과 학기·팀 화면의 전체 구조 개편은 이번 파일 이관 범위에 포함하지 않는다.
