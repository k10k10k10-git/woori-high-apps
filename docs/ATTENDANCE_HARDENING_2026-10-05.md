# 출석부 감사 후 8개 개선

범위: 학생 앱 UI·조회·세션 초안. 운영 원장/출석 직접 수정, 데이터 마이그레이션, Rules 변경은 없음.

1. 과거 출석 오연결: 영구 personId 우선, 옛 자료는 이름과 생년월일/학생 연락처로 확인. 중복·SID 재사용·내부 ID 충돌은 연결 보류.
2. 통계 불일치: 현재와 과거의 해당 연도 행사 정보와 기존 calcStats를 사용. 미입력/행사를 출석률 분모에서 제외.
3. 이력 가독성: 월별 수치와 안내 12px, 더 진한 색상, 오류 재시도 버튼/초점 표시.
4. 초안 유실: 연도·반·종류별 세션 초안 유지, 새로고침 경고, 실패 보존, 제출한 버전만 성공 시 제거, 저장 중 재진입 중복 차단.
5. 명단 표시 차이: 개인 상세·상세 표·CSV·XLSX의 주소/생년월일/연간 출석률/등급 일치. 현재 검색·필터 결과만 내보냄.
6. 무기록 오해: 평균 출석률/이력/명단에서 무기록을 0%·D로 표시하지 않음. 실제 결석 기록만 있으면 0%·D 유지.
7. 심방 업무 연결: 새 요청에 기존 personId 함께 보관, 이동 후 현재 소속 필터/연락처/이력 연결. 원래 요청 경로에서 상태 관리. 옛 요청의 모호한 연결은 확인 대상으로 표시.
8. 조회 실패 은폐: 오류/무기록/연결 불확실/미래 연도 구분. 과거 조회 15초 제한·재시도·대상 전환 후 늦은 응답 무시.

검증:

- 앱 전체 테스트 497 통과, 에뮬레이터 전용 10개 로컬 건너뜀(별도 CI 대상).
- 타입 검사·정적 빌드·운영 산출물 경계 검사 통과. lint 오류 없음, 기존 경고 16개.
- 운영 SDK/인증/쓰기 차단 합성 브라우저: 모바일 이력 가독성/ID 충돌/조회 오류, 심방 이동 연결/이력 열기·ESC 닫기, 교사 초안 화면 전환 보존·쓰기 실패 보존, PC 명단 상세 및 실제 다운로드 확인.
- Impeccable 변경 UI 정적 탐지 결과 없음. 이는 앱 전체 무결점 또는 운영 인증 E2E 통과를 뜻하지 않음.
- 운영 실제 학생에 대한 로그인/쓰기 E2E는 수행하지 않음. 배포 후 공개 페이지·배포 파일 버전만 읽기 전용 확인.

초안은 브라우저 저장소에 남기지 않으며 새로고침/로그아웃 시 폐기된다. 이전 학생 정보가 부족한 과거 자료는 억지로 이어 붙이지 않으며 자동 데이터 복구는 포함하지 않는다.
