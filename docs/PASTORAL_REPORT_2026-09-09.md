# 목양 리포트

학생 출석부 관리자 메뉴 `/pastoral`에 새친구 정착현황·연속 결석·이번 주 요약을 추가한다. 기존 관리자 셸과 밑줄 선택·중립 배경·보라색 동작을 유지하며 모바일에서 학생 행을 세로로 배치한다.

## 범위와 기준

- 조회 연도와 기준 주일, 부서·학년·반·이름·담임 검색. 정상 주일 3회 이상 X만 연속 결석으로 집계하며 미입력은 결석이 아니다. 기존 장결은 분리한다.
- 연락처는 기존 학생 명단의 학생·보호자 번호로 전화 연결한다. 새 연락처 원장이나 자동 연락 기능을 만들지 않는다.
- 새친구 등록일 이후 첫 4회·8회의 출석 수, 경과 회수, 미입력 수와 마지막 출석을 표시한다. 출석 양호는 정착 완료 판정이 아니다.
- 등록 자료는 해당 연도 1학기·2학기·주일 새친구 공개 원장에서만 읽는다. 현행 권한이 없는 출석부 전용 관리자에게는 실패 안내·재시도를 제공하고 출석부 nf_ 연결 명단만 표시한다. 이를 전체 새친구 집계로 설명하지 않는다. 비공개 메모·연락처 원장은 읽지 않는다.
- 주간 요약은 현재 필터를 적용한 일반 학생 3회 연속 결석·등록 자료로 확인한 새친구 2회 연속 결석·3회 결석 후 재출석·기준 주일 미입력을 보여준다.
- 반 이동은 정확한 rosterSync 연결 또는 연도 내 유일한 personId만 사용한다. 연결이 끊겼거나 등록일이 없으면 확인 필요로 표시한다. 과거 연도·이름 추정 연결은 하지 않는다.

## 검증과 운영 경계

운영 DB 직접 쓰기·Rules·계정 변경 없음. 학생 앱 Hosting만 배포한다. 새로운 읽기 소비자는 DB_OWNERSHIP.md에 기록하며 공유 데이터 형태는 바꾸지 않는다. 상세 검증·PR·배포 결과는 완료 후 이 문서에 기록한다.

합성 QA는 실제 Report·AdminWorkspace·AppProvider·계산 모델을 사용하고 DB 경계와 인증을 가상 구현한다. 운영 인증 화면 검증과 구분한다.

- 실제 컴포넌트 합성 브라우저: PC 1440px, 모바일 375/320px 세 탭 가로 넘침 없음. 장결 필터·검색·초기화·조회 오류·재시도·교사 차단 통과. 독립 Impeccable finish review 결과 `ship`, material fixes 없음. 캡처는 로컬 `.impeccable/review/pastoral/`.
- 코드 검사는 lint 0오류(기존 경고 18), typecheck·정적 build 통과. 테스트 362개 통과, 별도 에뮬레이터용 기존 3개 skip. PR·운영 배포는 아래 완료 기록을 참조한다.
- ego-browser DOM 조회는 성공했으나 캡처가 시간 초과되어, 설치된 Playwright의 별도 합성 브라우저로 캡처·실행 검증했다. 운영 로그인 전체 E2E와 운영 데이터 입력 검사는 하지 않았다.
