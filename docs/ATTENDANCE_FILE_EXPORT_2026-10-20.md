# 출석부 파일화 (2026-10-20)

## 사용자 요청과 범위

관리자 여섯 번째 업무 메뉴 `/files`에서 전체 명단, 반별 출석부, 연속 결석 명단, 다시 출석 명단을 선택해 Excel 파일을 만든다. 기존 화면의 개별 내보내기는 유지한다. 학생·출석·행사 원장을 기존 구독 결과로 읽으며 DB 직접 쓰기, 새 구독·경로, Rules 배포, 계정 변경은 없다.

첨부된 2025년 출석부는 월별 날짜가 가로로 이어지는 반별 시트 구조의 참고 자료다. 원본의 개인정보·출석 값은 새 코드나 테스트에 복사하지 않는다. 18:34 후속 요청으로 연락처 파일은 학생 이름·본인 연락처·보호자 연락처·소속 반·장결 구분·연속 결석 횟수·마지막 출석일 순서로 변경한다. 복귀 파일의 횟수는 복귀 직전 연속 결석이다.

## 사용 흐름

- 전체 명단: 1부와 2부를 각각 내려받는다. 다른 화면의 검색·학기·반 필터를 적용하지 않는다. 장결 학생도 분류를 표시해 포함한다.
- 반별 출석부: 부서·학년·반을 고르면 조회 연도 전체 주일의 O/X, 출석률, 등급을 내려받는다.
- 연속 결석·다시 출석: 기준 주일과 정렬을 고른다. 전체 부서·학년·반, 장결 학생을 포함하며 학생·보호자 연락처를 문자열로 보존한다.
- 계정·연도·조회 조건·자료 세대가 바뀌거나 화면을 벗어나면 지연 중인 파일 내려받기를 중단한다. 생성 실패에는 다시 시도할 수 있는 오류를 표시한다.

## 집계 원칙

연간 파일은 모든 주일 날짜를 표시한다. 18:34 후속 요청으로 장결자의 지난 정상 주일 빈칸만 Excel용 사본에서 X로 표시·집계한다. 실제 입력된 O/X, 일반 학생 미입력, 미래 날짜와 원본 DB는 바꾸지 않는다. 행사 주일은 날짜와 행사 표시를 유지하고 출석률 분모에서 제외한다. 출석률은 사본의 `calcStats` O/(O+X), 등급은 기존 A≥90/B≥80/C≥70/D 기준이며 요약·학생 명단·연간·반별 시트가 같은 집계를 사용한다. 장결 보완은 파일·화면에 명시하며 실제 원장의 `입력 기록`과 혼동하지 않게 요약 열을 `집계 기록(O·X)`로 표시한다. 과거 연도는 연말까지, 미래 연도는 다운로드를 허용하지 않는다.

`buildPastoralReport`의 확인된 3회 이상 연속 X 및 복귀 직전 연속 X를 그대로 사용한다. 미입력에서 연속 계산을 끊으며 화면에서 미입력을 결석으로 치환하지 않는다.

## 완료 버튼 없는 출석 입력 검토

이번 변경은 파일화 기능이며 교사 O/X 저장 방식과 과거 출석은 변경하지 않는다. 단일 출석 버튼과 자동 저장은 구현 가능하지만, 아무 입력 없는 반의 전원 결석/교사 미입력은 자동 구분할 수 없다. 첫 O 이후에도 입력 완료/중도 이탈은 판정할 수 없다.

교사 완료 버튼을 없애려면 관리자 일괄 마감 또는 정해진 주일 마감과 전원 결석 예외 확인을 별도로 설계해야 한다. 새로 들어온 것만으로 결석을 저장하거나 페이지 종료·유휴시간을 완료 신호로 사용하지 않는다. 공유 `attendance`의 의미가 바뀌는 별도 작업이므로 이번에 임의 적용하지 않는다.

## 검증 및 배포

순수 로직·XLSX 직렬화/재읽기·다운로드 세대 가드·역할 제한·PC/모바일 실제 다운로드·합성 DB 불변을 검증한다. 운영 데이터에 시험 학생이나 출석을 쓰지 않는다. 검증, PR, Hosting 배포 및 공개 산출물 대조의 실행 결과는 로컬 `outputs/attendance-file-exports-20261020/RESULT.md`에 기록한다. CI 합성 인증·저장 검사는 운영 관리자 E2E 또는 실제 Excel 앱 수동 검증과 구분한다.
